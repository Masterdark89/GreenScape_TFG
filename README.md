# GreenScape_TFG


Aplicacion movil desarrollada con Flutter para gestionar funcionalidades orientadas a cliente y trabajador, incluyendo chat, inventario, pago, rutas y perfiles.

## Como iniciar el proyecto

### 1. Requisitos previos

- Tener instalado Flutter SDK.
- Tener configurado un dispositivo Android/iOS o un emulador.
- Tener instalado Android Studio o VS Code con extensiones de Flutter/Dart.

### 2. Instalar dependencias

Desde la raiz del proyecto ejecuta:

```bash
flutter pub get
```

### 3. Ejecutar la aplicacion

Para iniciar la app en un dispositivo conectado o emulador:

```bash
flutter run
```

### 4. Comprobar configuracion de Flutter (opcional)

Si necesitas validar que el entorno esta correcto:

```bash
flutter doctor
```
